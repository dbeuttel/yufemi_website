# Launch Checklist: SEO + AI Visibility

_Print this or copy it into the project's issue tracker. Details for each item are in [SEO-AI-VISIBILITY-PLAYBOOK.md](SEO-AI-VISIBILITY-PLAYBOOK.md)._

**Site:** ____________________  **Launch date:** __________  **Checked by:** __________

## Before launch
**Facts & content**
- [ ] Facts Sheet complete and approved (`templates/facts-sheet.md`)
- [ ] Every page has a unique title (≤ 60 chars) and meta description (≤ 155 chars)
- [ ] One H1 per page; headings in order
- [ ] Key questions answered in the first sentence or two under their headings
- [ ] About and Contact pages have real people and real details
- [ ] No placeholder text ("Lorem ipsum," "Sample page," "Hello world," template copy)
- [ ] All claims accurate and sourced; YMYL content expert-reviewed; disclaimers present
- [ ] Images have alt text; share image (1200×630) set

**Technical**
- [ ] Main content visible in page source (not JavaScript-only)
- [ ] `robots.txt` allows search + AI crawlers; links the sitemap
- [ ] CDN, host and security-plugin bot blocking reviewed (AI crawlers not blocked by accident)
- [ ] `sitemap.xml` lists only live, canonical, indexable pages
- [ ] Canonical tags set; one preferred domain (https, www or non-www) with redirects
- [ ] No `noindex` left over from staging
- [ ] Old URLs 301-redirected (redesigns and migrations)
- [ ] Custom 404 page returns a real 404
- [ ] PageSpeed (mobile): LCP < 2.5 s, INP < 200 ms, CLS < 0.1
- [ ] Zoom not disabled; contrast, focus states and form labels pass an axe or WAVE check
- [ ] HTTPS + security headers; privacy policy live
- [ ] Structured data added, matches visible content, passes the Rich Results Test
- [ ] `llms.txt` added (optional)
- [ ] Forms, checkout and email addresses tested end-to-end

## Launch day
- [ ] Google Search Console verified; sitemap submitted; homepage indexing requested
- [ ] Bing Webmaster Tools verified (import from GSC); sitemap submitted
- [ ] IndexNow set up (if CMS or host supports it)
- [ ] Analytics live; conversions defined; AI-referral segment created
- [ ] Google Business Profile / Bing Places / Apple Business Connect updated (if applicable)
- [ ] Merchant Center and ChatGPT merchant feed submitted (if e-commerce)
- [ ] Social profiles updated with the new URL and Facts Sheet details

## First 30 days
- [ ] Weekly: Search Console and Bing coverage errors fixed
- [ ] Review requests going to customers or users
- [ ] 5+ quality directory or association listings live
- [ ] First AI visibility check logged (`templates/ai-visibility-log.md`)
- [ ] One outreach effort done (local press, partner, roundup author)
